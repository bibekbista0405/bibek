The story behind

INK

"I Need To Know" — a social platform.

01

The idea

Not a mockup — a real social platform. Registration, login, username verification, and a genuine frontend/backend split, built end to end.

02

The stack

React on the frontend, talking to a Node.js + Express backend, with Firebase handling auth and data.

React Node.js Express Firebase
03

Building it

A real registration-and-auth flow across a split frontend/backend means the unglamorous parts show up fast — keeping the client and API in sync, handling auth state properly, and getting the whole thing actually deployed rather than just running on localhost.

04

Where it stands

Active build

The story behind

DASH

A privacy-first desktop browser.

01

The idea

Not a browser extension bolted onto Chrome — an actual desktop browser, built to put user control and privacy front and center.

02

The stack

A React + TypeScript renderer inside Electron, talking to native services over IPC, with SQLite for local storage and Zustand managing state.

Electron React TypeScript SQLite
03

Building it

A desktop browser goes deeper than a typical web app — state has to move safely between the renderer and the main process over IPC, and storage means picking (and actually using) something like SQLite instead of leaning on a web API.

04

Where it stands

Active build
It's a desktop app, so there's no live web link — but the source is public.
